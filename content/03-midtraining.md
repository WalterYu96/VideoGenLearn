# 3. 中训练（Continue Training / Mid-training）

> [!结论] 本章结论
> 视频领域很少叫 “mid-training”，各家报告里叫 **Continue Training（CT）**。它夹在大规模预训练和小规模 SFT 之间，数据量约是预训练的 1/5–1/10（Waver：720p 预训练 2200 万 → CT 400 万；HunyuanVideo 1.5：每个任务约 100 万）。它做三件事：**质量退火、能力扩展、任务注入**。

```flow
大规模预训练 | 数千万到上亿片段
质量退火 | 美学 + 运动双高子集，LR 衰减
能力扩展 | 时长、多镜头、分辨率 / 帧率、音频分支
任务注入 | I2V / 插帧 / 续写 / 参考 / 编辑
SFT 与 RL | 以退火后的 checkpoint 为起点
```

## 3.1 质量退火

- **数据**：按美学分 + 光流运动分双高筛选的子集（Seedance 1.0）；增加清晰度、色彩平衡维度并做来源 / 类别均衡（Waver）。
- **学习率**：类似 LLM 的退火阶段，lr 逐步衰减；退火后的 checkpoint 是 SFT / RL 的起点。

> [!注意] 与 T2I 的差异
> 视频的“高质量”必须同时看运动。只用美学分筛选会偏向静态风景和慢镜头，导致模型“不动”。

## 3.2 能力扩展

- **时长**：5s → 10s → 15s+。手段是逐步加长帧数、调整时间 RoPE（外推或插值），并配合稀疏 / 窗口注意力控制成本。
- **多镜头叙事**：用带切镜的长片段 + 分镜 caption 训练（如 Seedance、Kling 3.0 单次最多 6 个镜头）；学术端可参考 LCT（Long Context Tuning），在场景级上下文中做镜头间注意力。
- **分辨率 / 帧率**：主模型到 720p、24fps 为止，1080p–4K 由级联超分完成（HunyuanVideo 1.5 VSR 用 1K–4K 数据约 100 万；Kling-Omni 超分以低分辨率 latent 和多模态条件为输入）。
- **音频分支接入**：在已训好的视频模型旁接一条音频流，先冻结视频、再联合训练，是常见的成本优化路线（Ovi、LTX-2 的非对称双流即此思路）。

## 3.3 任务注入

- **统一条件接口**：噪声 latent + 条件帧 latent + 二值 mask 沿通道拼接（Waver），任意帧都可以是条件：

| mask 模式 | 对应任务 |
|---|---|
| 首帧为条件 | I2V |
| 首尾帧为条件 | 插帧 |
| 前 N 帧为条件 | 续写 |

- **参考与编辑**：Kling-Omni 在 CT 阶段注入参考生视频、图像 / 视频编辑、图–视频–文本交错条件等任务，再进入 “quality-tuning”。
- **任务配比**：逐步上调业务主力任务的比例（I2V 20% → 40%），同时保留 T2I / T2V 防止遗忘。
- **模型融合**：Seedance 1.0 在不同子集上分别训练再融合；Waver 融合 7–10 个模型。T2I 的 model soup 经验可直接用。

## 3.4 各家中训练配方对比

| 模型 | 中训练做什么 | 数据 / 超参 |
|---|---|---|
| Seedance 1.0 | 美学 + 光流运动双高子集退火；I2V 比例从 20% 提到 40% | 规模未公开 |
| HunyuanVideo 1.5 | 分任务继续训练，再进入 SFT | 每个任务约 100 万片段 |
| Waver | 720p CT，加入清晰度和色彩平衡过滤，并做来源与类别均衡 | 400 万视频 + 1500 万图像 |
| Kling-Omni | 注入参考生视频、图像 / 视频编辑、图–视频–文本交错条件，再做 quality-tuning | 规模未公开 |
| MAGI-1 4.5B | 720p、最长 16s 阶段即拉长时长的中训练 | LR 从 1e-4 降到 1e-5 |
| Step-Video-T2V | 544×992 高分辨率阶段 | 2730 万样本，LR 2e-5 → 1e-5 |

## 3.5 实操清单

1. **LR**：CT 从预训练末期 LR 的一小部分起步，再退火到约 1e-5（MAGI-1、Step-Video 都收在这个量级）。
2. **防遗忘**：保留一部分预训练分布的数据和图像数据（Waver CT 仍混 1500 万图像），否则概念覆盖和文字渲染会退化。
3. **拉长时长时同步调 shift**：帧数和分辨率变大后，最优 timestep shift 也变大（Seedance 1.0 的分辨率感知 shift）；不调会出现布局崩坏或运动变弱。
4. **多镜头数据**：用多镜头长片段，每个镜头配独立 caption，并用 MM-RoPE 一类编码区分镜头与文本位置。
5. **新任务的 mask 设计**：通道拼接统一接口下，新任务就是一种新的 mask 模式；序列拼接的参考则要新增类型 embedding，并从零初始化。
6. **验证**：每个阶段固定一套 prompt 和首帧集，配合 VBench 与内部 GSB 人评；把运动幅度单独监控，防止退火后变“不动”。
