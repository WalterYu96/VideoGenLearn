# 4. 后训练：SFT、RL、蒸馏、OPD

> [!结论] 本章结论
> 头部厂商的后训练顺序基本是：**SFT（小而精）→ 偏好 / RL（多奖励）→ Prompt 改写器 RL → 步数 + CFG 蒸馏（可选自回归蒸馏）**。一份 2026-04 的系统性后训练工作报告显示：RLHF 带来 +31% GSB，Prompt 增强再 +20%（[来源](https://www.alphaxiv.org/abs/2604.25427.md)）。2026 年起，**OPD（在线策略蒸馏）**开始把“多个 RL 专家合并”和“少步 / 自回归蒸馏”串到一起。

```flow
SFT | 数百到 10 万条类别均衡、人工核验的片段，为 RL 提供好的起点
奖励模型 | 对齐 / 美学 / 运动 / 物理 / 音画同步
偏好与 RL | DPO / ReFL / GRPO 系 / DiffusionNFT
Prompt 改写器 RL | 冻结生成器，训练 LLM 改写器
蒸馏 | 步数 + CFG 蒸馏，可选自回归蒸馏
OPD | 学生自采样轨迹上的教师稠密监督
```

## 本章四个小节

| 小节 | 解决什么问题 | 训练信号 | 典型做法 |
|---|---|---|---|
| [4.1 SFT](#/post-sft) | 把预训练模型拉到“高质量、可控”的分布，给 RL 一个好的参考策略 | 精选视频片段的 flow matching 损失 | 小规模、类别均衡、人工核验；分类别训练后融合 |
| [4.2 RL](#/post-rl) | 对齐人类偏好：画质、运动、指令遵循、音画同步 | 奖励模型打分或人工偏好对 | Flow-DPO、ReFL、GRPO 族、DiffusionNFT；多奖励加权 |
| [4.3 蒸馏](#/post-distill) | 把 50 步 × 2 次 CFG 压到几步，降低推理成本 | 教师模型的轨迹、分布或判别器 | CFG 蒸馏 + 一致性 / 分布匹配 / 对抗蒸馏；自回归蒸馏做流式生成 |
| [4.4 OPD](#/post-opd) | 用更强的教师在学生自己的轨迹上给稠密监督 | 教师的速度场 / score / 判别器 | DMD、Self-Forcing、DiffusionOPD：多专家合并、长视频纠偏 |

> [!提示] 实战专题
> 以 33B 音视频模型 MiniMax-H3 为例，从 GSB 人工标注到 LoRA Flow-DPO、再到在线 RL 的完整调研与落地方案，见 [4.A MiniMax-H3 后训练调研与落地方案](#/h3-rl)。

## 各阶段怎么衔接

1. **SFT 是 RL 的起点，不是画质的主力**：SFT 数据量很小，主要作用是把输出分布收窄到高质量区域，让后面的 RL 和 DPO 有一个好的参考策略。
2. **一般先 RL 再蒸馏**：蒸馏时用 RL 后的模型当教师，否则学生会丢掉 RL 收益。也有团队反过来，直接在蒸馏后的少步模型上做 RL，因为 rollout 便宜得多。
3. **OPD 把两条线连起来**：按维度分别 RL 出多个专家，再用 OPD 合并成一个学生；步数蒸馏和自回归蒸馏本身也可以看作 OPD 的特例。
4. **评测贯穿全程**：每一步都要和上一步的模型做 GSB 人评，并盯住运动幅度、多样性有没有下降。

```flow
基础模型 | 预训练 + 中训练质量退火
SFT | 收窄到高质量分布
RL | 多奖励偏好对齐，必要时分维度训多个专家
OPD | 把多个专家合并成一个学生
蒸馏 | 少步 + CFG 蒸馏；需要实时时做自回归蒸馏
上线 | 推理加速见第 7 章
```

> [!注意] 最常见的失败
> 运动坍缩（越训越静态）和奖励作弊。每一轮 RL 或蒸馏之后，都要单独检查运动幅度和多样性，而不是只看总分。细节见 [4.2 RL](#/post-rl)。
