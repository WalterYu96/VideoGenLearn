# 4.4 OPD：在线策略蒸馏

> [!结论] 一句话
> OPD（On-Policy Distillation）= **在学生自己采样的轨迹上，让教师给逐步的稠密监督**。它兼有 RL 的“在策略”（训练分布 = 推理分布，没有 exposure bias）和 SFT 的“稠密信号”（每个 token / 每个去噪步都有监督）。LLM 里 Qwen3、MiMo-V2-Flash、GLM-5 的后训练都用了它；2026 年起它被系统地迁移到扩散与视频：多任务专家合并（DiffusionOPD）、黑盒教师蒸馏（AFD）、长视频自蒸馏（OPSD-V）、图像教师教视频学生（MILD）。

> [!注意] 资料说明（2026-11）
> 扩散 / 视频 OPD 的论文几乎都是 2026 年的 arXiv 预印本，多数还没有同行评审，实验多在 1.3B 级学生或 SD3.5-M 上。下文数字均来自论文原文，只代表其设定下的结果。

## 三种后训练信号对比

| | 采样来源 | 信号密度 | 典型问题 |
|---|---|---|---|
| SFT / 离线蒸馏 | 教师或数据（off-policy） | 稠密（每个 token） | 学生在推理时走到训练没见过的状态，误差累积（exposure bias） |
| RL | 学生自己（on-policy） | 稀疏（整条轨迹一个奖励） | 样本效率低，需要奖励模型，易 reward hacking |
| **OPD** | 学生自己（on-policy） | 稠密（教师对每步打分） | 需要一个更强、且“合得来”的教师；教师前向有成本 |

上表即 Thinking Machines 博客里的划分（[来源](https://thinkingmachines.ai/blog/on-policy-distillation)）。

## LLM 中的 OPD

### 起源

| 工作 | 时间 / 机构 | 贡献 |
|---|---|---|
| [MiniLLM](https://arxiv.org/abs/2306.08543) | 2023-06，ICLR 2024（Gu, Dong, Wei, Huang） | 把标准 KD 的前向 KL 换成**反向 KL**，避免学生高估教师的低概率区域，并推导了在策略优化方法 |
| [GKD](https://arxiv.org/abs/2306.13649) | 2023-06，ICLR 2024（Google DeepMind，Agarwal 等） | 在**学生自己生成的序列**上用教师概率做标签，散度可换（前向 KL / 反向 KL / 广义 JSD），并可与 RL 微调结合 |
| [Qwen3 技术报告](https://arxiv.org/abs/2505.09388) | 2025-05，阿里 Qwen | 小模型“强到弱蒸馏”：先离线蒸馏，再在策略蒸馏（教师 Qwen3-32B 或 235B-A22B） |
| [On-Policy Distillation 博客](https://thinkingmachines.ai/blog/on-policy-distillation) | 2025-10，Thinking Machines（Kevin Lu） | 把方法讲透并给出成本对比，让 OPD 在社区流行 |

### 目标函数

学生 $\pi_\theta$ 采样 $\hat y\sim\pi_\theta(\cdot\mid x)$，教师 $\pi_T$ 在同一前缀上打分。序列级反向 KL 可精确分解为逐 token 反向 KL 之和（[来源](https://arxiv.org/html/2604.13016)）：

$$\mathcal{L}_{OPD}=\mathbb{E}_{x,\;\hat y\sim\pi_\theta}\sum_t D_{KL}\big(\pi_\theta(\cdot\mid x,\hat y_{<t})\,\|\,\pi_T(\cdot\mid x,\hat y_{<t})\big)$$

实现上有三种：全词表 KL、只在采样 token 上做单样本估计（无偏）、top-k 近似。工程上常写成 RL 形式：每个 token 的优势取 $A_t=\mathrm{sg}\big[\log\pi_T(\hat y_t)-\log\pi_\theta(\hat y_t)\big]$，折扣因子为 0，直接复用 GRPO / PPO 基础设施（[Thinking Machines](https://thinkingmachines.ai/blog/on-policy-distillation)、[GLM-5](https://arxiv.org/abs/2602.15763)、[MiMo-V2-Flash](https://arxiv.org/abs/2601.02780)）。

> [!提示] 为什么是反向 KL
> 前向 KL $D_{KL}(\pi_T\|\pi_\theta)$ 是“覆盖”型：学生要把概率摊到教师所有模式上，容量不足时会在模式之间糊成一片。反向 KL 是“寻模”型：学生只需在自己走到的地方贴近教师，不会高估教师的低概率区域（[MiniLLM](https://arxiv.org/abs/2306.08543)）。代价是多样性可能下降，扩散里的 DMD 也有同样的问题（见下文失败模式）。

### 成本与收益数字

| 来源 | 设定 | 结果 |
|---|---|---|
| [Qwen3 报告 表 21](https://arxiv.org/html/2505.09388v1) | Qwen3-8B，从离线蒸馏检查点出发 | AIME'24：离线蒸馏 55.0 → RL 67.6（17,920 GPU 时）vs **OPD 74.4（1,800 GPU 时）**；AIME'25：42.8 → 55.5 vs **65.5**；OPD 的 pass@64 也更高（93.3 vs 90.0），约 1/10 算力 |
| [Thinking Machines](https://thinkingmachines.ai/blog/on-policy-distillation) | Qwen3-8B-Base 学生，Qwen3-8B 教师（作者注：比 32B 教师略好） | SFT 400K 条 → AIME'24 60%；再 OPD 约 150 步到 70%；外推 SFT 要约 2M 条才到 70%，OPD 便宜 **9–30×**（是否计教师采样成本） |
| 同上 | 个性化：内部文档中训后指令遵循掉了 | IF-eval 85% → 中训后 79% → OPD 后 **83%**，知识分不降（36% → 41%） |
| [MiMo-V2-Flash](https://arxiv.org/html/2601.02780v1) | 309B MoE，多教师 OPD（MOPD） | AIME 2025 89.3 → **94.1**（最强教师 93.9）；LiveCodeBench 77.5 → 83.2（教师 82.6）；但 SWE-Bench Verified 73.4 < 教师 74.2，BrowseComp 45.4 < 教师 51.7 |

### 大模型后训练里怎么用

| 模型 | 用法 |
|---|---|
| Qwen3（2025-05） | 小模型蒸馏的第二阶段：先离线蒸馏打底，再 OPD 对齐教师 logits（[来源](https://arxiv.org/abs/2505.09388)） |
| MiMo-V2-Flash（小米，2026-01） | **多教师 OPD（MOPD）**：先 SFT，再按领域训练 RL / SFT 专家（数学、代码、搜索、安全等），最后每个 prompt 用对应领域的教师做 OPD；优势 = 教师 log 比 + α × 结果奖励优势，即 OPD 和 RL 叠加（[来源](https://arxiv.org/abs/2601.02780)） |
| GLM-5（智谱，2026-02） | **跨阶段在策略蒸馏**：顺序做推理 RL → 智能体 RL → 通用 RL 会遗忘，最后一阶段用前面各阶段的最终检查点当教师做 OPD；GRPO 组大小设为 1、batch 1024（[来源](https://arxiv.org/abs/2602.15763)） |

> [!经验] 共同的模式
> **“先分领域练专家，再用 OPD 合并到一个学生”**。专家各自用 RL 探索，互不干扰；合并阶段用稠密信号，比多奖励联合 RL 稳定。扩散里的 DiffusionOPD 是同一个思路。

### Rethinking OPD：什么时候有效

[Rethinking On-Policy Distillation](https://arxiv.org/abs/2604.13016)（上海科技大学、清华、UIUC、人大，2026-04；只做了数学推理）：

1. **教师要有学生没有的新能力**：同一流水线出来的教师（如 1.5B / 7B 的 R1-Distill）对学生来说“分不出区别”，蒸了没用；再做过 RL 的教师收益明显更大。JustRL-1.5B 当教师时学生收回了 80% 以上的差距，而分数更高的 R1-Distill-7B 当教师却几乎没提升。
2. **思维模式要兼容**：Qwen3-1.7B-Base 学生上，GRPO 训出的 Qwen3-4B-Base-GRPO 教师初始 top-k 重叠更高，效果好于分数更高的 Qwen3-4B 非思考教师。成功的 OPD 里，学生访问状态上的高概率 token 重叠率从 72% 升到 91%，共享 top-k 占 97–99% 的概率质量。
3. **救失败的 OPD**：①离线冷启动：先用教师生成的 20 万条回答 SFT，再在约 3 万条剩余 prompt 上 OPD；②用教师后训练用过的 prompt（但会降低学生熵，要混入分布外 prompt）。
4. **长轨迹会变差**：截断前缀让教师续写，教师的准确率优势从 1K 前缀时 +0.37 降到 16K 前缀时 +0.02，稠密信号随深度变得不可靠。

## 扩散 / 视频中的 OPD

### 怎么从 token 迁移到去噪步

| LLM | 扩散 / 视频 |
|---|---|
| 一个 token | 一个去噪步的转移 $x_{t_j}\to x_{t_{j-1}}$，或自回归视频的一个 chunk |
| 教师 logits | 教师速度场 / score；黑盒时只有成品视频，用判别器代替 |
| 逐 token 反向 KL | 每步高斯转移之间的 KL（闭式），或分布级 KL 的 score 差梯度 |
| 学生 rollout | 学生少步采样 / 带 KV cache 的自回归 rollout |

DiffusionOPD 的推导（[来源](https://arxiv.org/html/2605.15055)）：SDE 采样（沿用 Flow-GRPO 的 Euler–Maruyama 离散）下，师生每步转移是协方差相同的高斯，KL 只剩均值差：

$$D_{KL}(p_S\|p_T)=\frac{\lVert\mu_S(x_{t_j};\theta)-\mu_T(x_{t_j})\rVert_2^2}{2\bar\sigma_j^2}$$

ODE 采样时退化为 $\tfrac12\lVert\mu_S-\mu_T\rVert_2^2$ 的 L2 转移匹配。论文认为这种解析梯度比把 KL 当奖励再跑 PPO 方差更低。

### 方法总表

| 方法 | 在谁的轨迹上 | 教师信号 | 损失 / 更新 | 用途与结果 |
|---|---|---|---|---|
| [DMD](https://arxiv.org/abs/2311.18828)（MIT + Adobe，CVPR 2024）/ [DMD2](https://arxiv.org/abs/2405.14867)（2024-05） | 学生少步生成的样本 | 教师 score − 学生分布的 fake score | 分布级反向 KL 的梯度；DMD 另加回归损失，DMD2 去掉回归、加 GAN | 步数蒸馏，可看作扩散 OPD 的前身；DMD2 ImageNet-64 FID 1.28，推理成本约降 500× |
| [Self-Forcing](https://arxiv.org/abs/2506.08009)（Adobe 等，NeurIPS 2025） | 自回归学生带 KV cache 的完整 rollout | 双向教师（视频级分布匹配：DMD / SiD / GAN） | 整段视频级损失 + 梯度截断 | 消除自回归 exposure bias；单张 H100 上 17 FPS、亚秒级延迟 |
| [DiffusionOPD](https://arxiv.org/abs/2605.15055)（复旦 + 阿里巴巴，2026-05） | 学生 SDE / ODE 轨迹访问到的状态 | 每个任务单独 RL 出的教师 | 上面的每步闭式 KL | **多任务专家合并**。SD3.5-M 文生图：GenEval 0.96 / OCR 0.94 / PickScore 23.99，平均 0.929，高于多任务 NFT（0.715）和级联 NFT（0.851），总耗时 97 h vs 128–148 h |
| [AFD](https://arxiv.org/abs/2605.26105)（NUS 等，2026-05） | 自回归学生的自条件 rollout | **黑盒教师**：Seedance 2.0 API，只给成品视频 | Bradley–Terry 判别器优势 + DiffusionNFT 式前向过程更新 + 先验正则 | Self-Forcing 学生 VBench Physics 87.55，高于 GAN 83.83、去掉 score 项的 DMD 式基线 81.88、SFT 58.69（基座 68.49） |
| [D-OPSD](https://arxiv.org/abs/2605.05204)（2026-05） | 少步学生自己的 rollout | 同一模型，额外以目标图像为条件（借 LLM/VLM 文本编码器的上下文能力） | 匹配两种条件下的预测分布 | 在 Z-Image-Turbo、FLUX.2-klein 这类步数蒸馏模型上继续学新概念 / 风格，而不丢少步能力 |
| [OPSD-V](https://arxiv.org/abs/2607.08766)（美团 + 港科大 + 城大，2026-07） | 学生自回归 rollout 及自身 KV cache | 同一模型，但旧历史换成真实视频 chunk 的“干净 cache” | 4 个去噪步上的稠密速度匹配，LoRA；无 DMD / 奖励 / 对抗 | 修 Self-Forcing / LongLive 的长视频误差累积；3,800 条 1 分钟视频、24 张 H800 训 200 步；用户研究总体偏好 66.0% |
| [HPSD](https://arxiv.org/abs/2608.13205)（2026-08） | 学生 T2V rollout，以教师轨迹点为离线锚点 | 同一模型的 TI2V 模式（高质量首帧 + 增强 prompt） | 速度级监督，离线锚点 + 在线 rollout 混合 | 把 TI2V 的“特权条件”能力转给 T2V（摘要无具体数字） |
| [DiffusionOPSD](https://arxiv.org/abs/2608.24646)（2026-08） | 冻结的行为策略（EMA 定期刷新）的轨迹 | 奖励梯度在锚点附近构造的正负目标 | 拟合 clean 预测目标 | 本质是 RL；20 个奖励设定中 19 个最好，GPU 时比 DiffusionNFT 少 40%（SD3.5-M）/ 63%（Z-Image-Turbo） |
| [MILD](https://arxiv.org/abs/2609.34371)（港大等，2026-09） | 视频学生 rollout | **图像专家**（GenEval、美学、OCR，SD3.5-M 骨干），线性 connector 对齐 latent | 修正限制在学生原预测附近 + 光流运动奖励 | 用便宜的图像教师提升视频，摘要称优于视频教师 OPD 基线（学生 Wan2.1-1.3B，视频教师 Wan2.1-14B） |
| [SMD](https://arxiv.org/abs/2610.18472)（2026-10） | 少步学生的在策略状态 | 多步教师速度 | 在策略速度回归 + pivot 残差 + 远离弱教师预测；不需要 fake score 或判别器 | 把 OPD 直接当成步数蒸馏方法：4 NFE，扩展到 33B，覆盖图像 / 编辑 / 3D / 视频 / 音视频（摘要无具体数字） |

### 和 4.3 蒸馏的关系

[4.3 蒸馏](#/post-distill) 讲的步数蒸馏和自回归蒸馏，很多本身就是“在策略”的：

| 4.3 里的方法 | 是不是 OPD | 区别 |
|---|---|---|
| 轨迹 / 一致性蒸馏（PCM、rCM） | 否，在教师 ODE 轨迹上回归 | off-policy，对应 LLM 的 SFT |
| DMD / DMD2 | 是（分布级） | 监督的是“学生输出分布”，要额外训一个 fake score 网络 |
| Self-Forcing / CausVid 后续 | 是（视频级） | 重点是自回归 rollout 与推理一致 |
| DiffusionOPD / SMD | 是（逐步） | 直接匹配每步转移，不需要 fake score，最接近 LLM 的逐 token OPD |

区别在目的：4.3 的目标是**减步数**（教师 = 同一个多步模型）；本节的 OPD 更多是**转移能力**（教师 = RL 专家、闭源 API、图像专家、带特权条件的自己）。

## 设计要点

### 教师选择

| 教师类型 | 例子 | 注意 |
|---|---|---|
| 更大 / 更强的同族模型 | Qwen3-32B → 8B；Wan2.1-14B → 1.3B | 要有学生没有的能力，同流水线教师可能无效（Rethinking） |
| 分任务 RL 专家 | DiffusionOPD、MOPD | 合并后可能略低于最强教师（MiMo 的 SWE-Bench、BrowseComp） |
| 前面阶段的检查点 | GLM-5 跨阶段蒸馏 | 用来对抗顺序 RL 的遗忘 |
| 闭源 API | AFD 用 Seedance 2.0 | 拿不到 score，只能用判别器；等价性证明依赖最优判别器和 $\pi_{old}=\pi_\theta$ 假设 |
| 自己 + 特权信息 | OPSD-V（真实历史）、HPSD（首帧）、D-OPSD（目标图像） | 不需要更大模型；特权条件要在推理时拿不到、训练时拿得到 |
| 异构模态 | MILD 图像专家教视频 | 只适合与时间无关的能力（美学、文字），运动要单独约束 |

### 训练流程

1. **冷启动**：学生先离线 SFT / ODE 回归 / 步数蒸馏到“和教师合得来”，再进 OPD（Qwen3 离线 → 在线；Rethinking 的 20 万条冷启动；Self-Forcing 沿用 CausVid 的 ODE 初始化（[来源](https://arxiv.org/html/2506.08009v2)））。
2. **在少步学生上做 OPD**：rollout 成本和步数成正比；OPSD-V、AFD、D-OPSD 都在 4 步级别的学生上训练。DiffusionOPD 的 SDE 版本每步都要跑教师前向，多步学生会很贵。
3. **与 RL 的组合**：可以叠加（MiMo：教师 log 比 + α·结果奖励），也可以“先分任务 RL，再 OPD 合并”（DiffusionOPD）。
4. **一个参考顺序**（组合推断，不是某篇论文的完整配方）：

```flow
SFT / 预训练检查点 | 学生冷启动
分维度 RL 专家 | 美学、运动、文字渲染各自 RL
OPD 合并 | DiffusionOPD 式逐步 KL，或 MOPD 式多教师
步数蒸馏 | DMD / rCM / SMD 到 4 步左右
自回归化 + 长视频修复 | Self-Forcing → OPSD-V 式自蒸馏
```

### 成本

| 项 | 说明 |
|---|---|
| 学生 rollout | 每步训练都要采样；视频比图像贵得多，所以优先在 480p、少步、1.3B 级学生上做 |
| 教师前向 | 白盒教师在学生状态上逐步前向；MILD 指出视频教师显存和查询延迟高，所以用图像专家 |
| 黑盒教师 | 每个 prompt 要调一次 API 拿成品视频，但不需要教师逐步前向 |
| 算力参考 | LLM：OPD 约为 RL 的 1/10 GPU 时（Qwen3）；扩散：DiffusionOPD 总耗时约为多任务 RL 的 2/3–3/4 |

### 失败模式

| 现象 | 原因 | 对策 |
|---|---|---|
| 学生不涨甚至退化 | 教师没有新能力，或思维模式不兼容 | 换 RL 后的教师；离线冷启动；用教师训练过的 prompt（[Rethinking](https://arxiv.org/abs/2604.13016)） |
| 长轨迹后段信号变差 | 学生前缀越长越偏离教师分布，教师打分不可靠 | 截断长度、分段，或对后段降权 |
| 多样性下降、过饱和 | 反向 KL 寻模；DMD 系在视频上同样出现 | [Data-Forcing Distillation](https://arxiv.org/abs/2606.18478)：一行改动把学生拉回真实数据分布，100–300 步微调 |
| 合并后某些领域低于专家 | 多教师信号冲突 | 加结果奖励（MOPD 的 α 项）或调整 prompt 比例 |
| 动态被“画质教师”削弱 | 图像教师只看单帧 | 修正限制在学生原预测附近 + 光流运动奖励（MILD） |
| 学到判别器的漏洞 | 黑盒对抗蒸馏本质是对抗训练 | 先验正则约束学生不偏离参考模型（AFD 的 $\lambda_{prior}=10^{-4}$） |

> [!提示] OPD 和 RL 怎么选
> 手上有比学生更强、且能在学生状态上打分的教师（大模型、RL 专家、带特权条件的自己）时，优先 OPD，样本效率高得多；只有奖励、没有教师时用 RL（[4.2 RL](#/post-rl)）。两者也可以直接相加。
